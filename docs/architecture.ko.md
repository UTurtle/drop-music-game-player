# 구조 설명

[English](architecture.md) · [한국어](architecture.ko.md)

`파일 → Web Audio 디코딩 → 모노 PCM → 전용 Worker → Easy/Hard 노트 → Player`

- **Creator:** 파일·제목과 선택적 영상 링크를 받습니다. 재생용 File 참조는 페이지 메모리에 유지합니다. 음원을 전송하는 API는 호출하지 않습니다.
- **DSP:** 22,050 Hz 모노, 1,024-point FFT, 양의 spectral flux, 국소 피크 선택과 결정적 밀도 제한을 사용합니다. 학습 모델·외부 추론 서비스는 없습니다. 완료·취소 시 Worker를 종료하며 취소 후 디코딩 결과는 버립니다.
- **Player:** Canvas, 두 레인과 여섯 개의 물리 키를 사용합니다. 로컬 오디오 currentTime 또는 공식 영상 플레이어 시계를 기준으로 판정합니다. 일시정지·버퍼링 중에는 미스를 쌓지 않고, 탐색하면 점수를 초기화한 연습 모드가 됩니다.
- **재생원:** 로컬 파일은 수명을 관리하는 object URL로, 영상은 자체 소리를 포함한 공식 플레이어로 재생합니다. 전환하면 이전 재생원을 정리합니다. 영상 오프셋은 로컬 음악 재생에 적용하지 않습니다.
- **언어:** EN/KO 상태와 브라우저 설정을 사용합니다. 언어를 바꿔도 선택 파일과 채보는 유지됩니다. Worker 오류는 수신한 뒤 번역합니다.
- **서버:** 개발 시 Vite middleware, 일반 실행 시 dist 파일을 제공합니다. 기본은 loopback 51100입니다. DB·세션 쿠키·업로드·게시 경로가 없습니다. 호환용 POST /api/charts는 403으로 거절합니다.
- **데이터:** 세션은 페이지 메모리에서만 유지됩니다. 앱은 언어 설정만 저장합니다. 영상 제공자와 데모 접속 경로의 네트워크 처리는 별도입니다.

테스트는 합성 음원과 모의 영상 이벤트를 사용합니다. 실제 곡의 재미·싱크나 플랫폼 정책 적합성을 인증하는 검증은 아닙니다. 의존성에는 각자의 라이선스가 적용되고, 프로젝트 라이선스는 사용자가 선택한 음악의 권리를 제공하지 않습니다.
